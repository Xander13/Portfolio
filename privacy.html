Privacy Policy


Effective Date: August 10, 2026





1. Overview


Welcome to the personal portfolio of Alex Kauffman. Your privacy is straightforward here: this site does not collect, track, or sell your personal data.





2. Interactive Assistant ("Essence")


"Essence" is not a real artificial intelligence model, automated bot, or machine learning agent. It is a front-end interface that processes structured JSON queries to simulate interactive responses locally in your browser. No messages, prompts, inputs, or outputs are collected, transmitted, or stored on any server.





3. Weather Feature & Location Data


The weather tool on this site requests permission to access your browser’s local geolocation data only if you explicitly select "YES" when prompted.


○   User Consent: Geolocation access is entirely voluntary. If you reject or decline the prompt, no location data is requested or processed.


○   No Data Retention: When permitted, your location coordinates are used instantly to fetch current weather conditions for your local session. This data is processed in real time and is never saved, logged, or stored.





4. Search Engine Indexing


This website allows standard search engine crawlers (such as Googlebot) to index public pages for search visibility using standard metadata tags:


○   <meta name="robots" content="index,follow">

○   <meta name="googlebot" content="index,follow">


These tags permit search engine crawlers to read public site content. They do not collect or track user interaction data.

AI-assisted development tools were utilized alongside custom code to build parts of this site's technical infrastructure.
