1. Overview


Welcome to the personal portfolio of Alex Kauffman. Your privacy is straightforward here: this site does not collect, track, or sell your personal data.





2. Interactive Assistant ("Echo")


Echo is a portfolio interface with two modes: Echo Normal and Echo Smart. Echo Normal uses structured JSON responses based on the questions recruiters, designers, and engineers commonly ask about Alex Kauffman's work, experience, and projects. It is a focused way to explore information already presented on this site.


Echo can also retrieve live information when you ask for it. Weather requests can use your local geolocation after you give permission, and stock requests pull current market data. These requests are made for the current interaction and are not stored on Alex Kauffman's server or in a database owned by this site.


Echo Smart uses Google's Gemini model when you want a deeper response. Your prompt is sent to Google's Gemini API through this site's server for that request. Gemini is used here to demonstrate what Echo can do, not to create a personal profile or store personal information. This is a personal development project and is not intended for professional use. Echo is Alex Kauffman's interface and an enabler of Alex's voice in the digital space. It brings together tools such as JSON, Yahoo Finance, weather services, and Google's Gemini model to make Echo more interactive.





3. Weather Feature & Location Data


The weather tool on this site requests permission to access your browser’s local geolocation data only if you explicitly select "YES" when prompted.


User Consent:

Geolocation access is entirely voluntary. If you reject or decline the prompt, no location data is requested or processed.



No Data Retention:

When permitted, your location coordinates are used instantly to fetch current weather conditions for your local session. This data is processed in real time and is never saved, logged, or stored.





4. Third-Party Data Sources


Echo includes optional features (such as web search, stock quotes, weather lookups, and Gemini mode) that send your query to third-party services to retrieve live information or generate a response. Gemini prompts are sent through this site's server to Google's Gemini API.


How Requests Work:

Web search, stock, and weather requests generally happen directly between your browser and the relevant third-party service. Gemini prompts are processed by this site's server only to forward them to Google's Gemini API. This site does not intentionally store the prompts or responses.



No Data Retention:

None of these queries or their results are logged, stored, or saved in any database associated with this website.





5. Local Storage & Cookies


This site does not use tracking cookies or advertising identifiers. It uses your browser's local storage only to remember your custom stock watchlist symbols between visits, entirely on your device. This data is never transmitted to or stored on any server.


Some password-protected project pages set a single cookie strictly to confirm that the correct password was entered. This cookie contains no personal data, only a signed, expiring access token, and is never used for tracking, analytics, or advertising.





6. Search Engine Indexing


This website allows standard search engine crawlers (such as Googlebot) to index public pages for search visibility using standard metadata tags:


○   <meta name="robots" content="index,follow">

○   <meta name="googlebot" content="index,follow">


These tags permit search engine crawlers to read public site content. They do not collect or track user interaction data.
